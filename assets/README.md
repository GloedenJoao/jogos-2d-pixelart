# Assets compartilhados

Pixel art gratuita (licença CC0) pra usar sem custo em qualquer projeto deste diretório:

- Kenney.nl — https://kenney.nl/assets (packs de pixel art, UI, áudio, tudo CC0)
- OpenGameArt.org — https://opengameart.org (filtrar por licença CC0)

Organize por tipo ao baixar: `assets/sprites/`, `assets/tiles/`, `assets/ui/`, `assets/audio/`. Sempre anotar a fonte e licença de cada pack baixado num arquivo `CREDITOS.md` aqui dentro, mesmo sendo CC0 — facilita não perder o rastro.
